# Multi-GAM Model Comparison for Biomass Gasification
This project conducts a comprehensive comparison of 10 Generalized Additive Model (GAM) variants (5 base models + their monotonic constrained versions) for predictive modeling of biomass gasification processes. The core goal is to balance predictive accuracy, physical conformity (alignment with chemical engineering physical laws), and model interpretability when predicting key gasification outputs including H₂, CO, CO₂, CH₄ (vol% N₂ free) and gas yield GY (Nm³/kg daf).

The implemented models cover mainstream GAM-based approaches: Explainable Boosting Machine (EBM), Classical GAM with splines (pyGAM), GA²M with pairwise interactions, Neural Additive Models (NAM), and Generalized Additive Mixed Models (GAMM). Each model has a standard version and a monotonic constrained version, with constraints designed to match the physical trends of biomass gasification, solving the problem of physically inconsistent predictions from pure data-driven models.

The project features a fully automated pipeline, including data preprocessing (sheet merging, unit conversion, one-hot encoding, outlier filtering, standardization), 5-fold cross-validation, model training and evaluation, publication-quality visualization, and optimal model selection. It evaluates models using multiple metrics (RMSE, MAE, R², MAPE) and a custom physical conformity rate (PhysRate) to quantify compliance with pre-defined monotonic constraints.

Rich visualization outputs are generated, including feature importance plots, train/test prediction scatter plots, residual analysis, model comparison boxplots, cross-model/target metric heatmaps, feature shape functions, ICE/PDP plots, and 3D bivariate dependency surface plots (for all 28 pairs of continuous features). All visualizations are saved in both PNG and PDF formats with a standardized publication style for academic and engineering use.

Additional utilities include automatic saving of trained models and scalers via joblib, generation of standalone prediction scripts for each model-target combination, and advanced analysis for the optimal model (highest PhysRate + highest R²) for each target variable. The pipeline ensures full reproducibility with fixed random seeds, detailed result logging, and comprehensive Excel summary tables for raw and aggregated cross-validation results.

The code is built with Python and leverages libraries such as NumPy, Pandas, Scikit-learn, Matplotlib, pygam, InterpretML, PyTorch, and SciPy. It includes robust error handling, automatic dependency checking, and configurable parameters (via the CFG class) for easy adaptation to different biomass gasification datasets and research requirements.
